# DSO Papers – Danish DSO tariff map

Interactive map of Danish distribution system operator (DSO) network tariffs, 2014–2026, for households and business customer classes.

**Live map:** https://notjakobkristensen.github.io/DSO-Papers/

Data: Energinet Datahub price lists (Energi Data Service), refreshed weekly. Research by Jakob Kristensen and Georgios Fotis (Aarhus University).
